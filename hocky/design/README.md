# کیت طراحی هاکی بازار (برای Adobe Illustrator)

همه‌ی بخش‌های بصری بازی در این پوشه به‌صورت **وکتور قابل ویرایش** آمده‌اند. هر فایل از هندسه، رنگ‌ها و تنظیمات واقعی بازی ساخته شده (`config/settings.json`)، پس دقیقاً با چیزی که روی زمین نمایش داده می‌شود هم‌اندازه و هم‌تراز است.

## قبل از شروع

1. فونت‌های پوشه‌ی `fonts/` (خانواده‌ی IRANSansX) را روی سیستم **نصب کنید**. بدون آن‌ها، متن‌های زنده در Illustrator با فونت دیگری باز می‌شوند.
2. برای اینکه متن فارسی در Illustrator درست نمایش داده شود، در پنل Paragraph گزینه‌ی
   **Middle Eastern & South Asian Every-line Composer** را انتخاب کنید.
3. همه‌ی اعداد بازی **لاتین** هستند (60، 7، 3·2·1)، نه فارسی.

## محتویات پوشه

| پوشه / فایل | چه چیزی دارد |
|---|---|
| `MarketHockey_DesignKit.pdf` | همه‌ی صفحه‌ها در یک PDF وکتور: زمین، گوی‌ها، نمادها، پدل و توپ، پالت رنگ، لوگوتایپ، تایپوگرافی و پیام‌ها. Illustrator هر صفحه را جداگانه باز می‌کند. |
| `svg/arena/arena_full.svg` | کل زمین در ابعاد واقعی (1080×1080) با **لایه‌های نام‌گذاری‌شده**: Background، Goals، Bumper_walls، HUD، Paddles، Mask و بقیه. |
| `svg/arena/layers/` | هر لایه‌ی زمین به‌صورت فایل جدا، روی همان آرت‌بورد 1080×1080. وقتی روی هم بگذارید، دقیقاً جفت می‌شوند. |
| `svg/elements/` | پدل هر بازیکن (شکل فعلی و نیم‌دایره‌ی کامل)، توپ‌ها (سفید، فیروزه‌ای، بنفش، طلایی) و دنباله‌ی نورانی توپ. |
| `svg/icons/` | نماد هر قابلیت روی آرت‌بورد 100×100، در دو نسخه‌ی سفید و تیره، به‌علاوه‌ی جام برنده. |
| `svg/orbs/` | گوی کامل هر قابلیت (هاله، بدنه، حلقه، نماد و حلقه‌ی زمان). نسخه‌ی سبز و قرمز هر گوی در پوشه‌ی `variants/` است. |
| `text/` | لوگوتایپ «هاکی بازار»، صفحه‌ی تایپوگرافی و **همه‌ی پیام‌های فارسی بازی**، هر کدام در دو نسخه: `_live` (متن قابل ویرایش) و `_outlined` (متن تبدیل‌شده به منحنی که همیشه درست دیده می‌شود). متن پیام‌ها در `persian_messages.json` هم هست. |
| `palette/` | پالت رنگ: `MarketHockey_colors.ase` (در Illustrator از پنل Swatches: Open Swatch Library → Other Library)، و نسخه‌های `colors.json`، `colors.css` و `palette.svg`. |
| `fonts/` | فونت‌های IRANSansX که بازی استفاده می‌کند. |
| `reference_screenshots/` | تصویر واقعی همه‌ی مراحل بازی، برای مقایسه و الهام. |
| `guide/` | راهنمای دو صفحه‌ای بازیکن (PDF وکتور). |

## برگرداندن طراحی به بازی

| چه چیزی | چطور وارد بازی می‌شود |
|---|---|
| **نماد قابلیت‌ها** | خروجی PNG شفاف 256×256 بگیرید و با نام دقیق قابلیت در `hocky/assets/icons/` بگذارید، مثلاً `expand.png`. بازی خودش آن را به‌جای نماد فعلی نشان می‌دهد. نام‌ها: `expand`، `shrink`، `speed_up`، `chaos`، `double_ball`، `trajectory_reveal`، `slow_down`، `dim_ball`، `shield`، `bull_market` |
| **رنگ‌ها** | کد HEX را در پنل تنظیمات بازی (`ControlPanel`) در بخش Colors وارد کنید و Save بزنید. |
| **فونت** | فایل TTF را در `hocky/assets/fonts/` بگذارید و در پنل تنظیمات، بخش HUD & Text → Fonts انتخاب کنید (مثلاً فونت Dana از هویت برند). |
| **متن پیام‌ها** | در پنل تنظیمات، بخش HUD & Text → Messages، و برای پیام هر قابلیت، صفحه‌ی همان قابلیت. |
| **اندازه‌ها** | اندازه‌ی دیواره‌ها، شعاع زمین، پهنای پدل، اندازه‌ی گوی‌ها و جای زمان و امتیاز همه در پنل تنظیمات قابل تغییرند. |
| **بقیه‌ی جزئیات** | دیواره‌ها، پدلها، دنباله‌ی توپ و پس‌زمینه با کد رسم می‌شوند. طرح نهایی را به‌صورت SVG یا PDF به تیم برنامه‌نویسی بدهید تا در بازی پیاده شود. |

## ساختن دوباره‌ی کیت

اگر تنظیمات بازی عوض شد، مثلاً اندازه‌ی دیواره یا رنگ‌ها، کیت را با تنظیمات جدید دوباره بسازید. داخل پوشه‌ی `hocky` اجرا کنید:

```bash
python3 tools/export_design_kit.py
```

برای ساختن PDF به Chrome یا Edge نیاز است. نسخه‌های outlined متن‌ها هم به PyMuPDF نیاز دارند (`pip install pymupdf`).
